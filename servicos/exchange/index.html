    Exchange

    Responsável: Gabriel — repositório pna26/exchange-service

    Microsserviço de câmbio em Python (FastAPI). Recebe um par de moedas, busca a cotação numa API de terceiros e devolve o preço de compra e de venda para o usuário logado.

    flowchart LR
    u([Usuário]) -->|"GET /exchange/USD/BRL<br/>cookie JWT"| lb[lb · Nginx] --> gw[gateway]
    gw -->|"+ header id-account"| ex[exchange]
    ex <-->|"hit (30 s)"| cache[(cache em memória)]
    ex -->|"miss"| api([AwesomeAPI])

    Contrato

    Método Rota Entrada Saída
    GET /exchange/{from}/{to} header id-account (posto pelo gateway) { sell, buy, date, id-account }

    O gateway também aceita /exchanges/{from}/{to} e reescreve para /exchange/....

    curl -H "Cookie: __store_jwt_token=$TOKEN" localhost:8080/exchange/USD/BRL

    { "sell": 5.3942, "buy": 5.3912, "date": "2026-11-05 10:00:00", "id-account": "8f1c..." }
    Status Quando
    200 cotação (do cache ou da API externa)
    400 moeda que não tem 3 letras (/exchange/US/BRL)
    401 sem token (barrado no gateway) ou sem id-account (não passou pelo gateway)
    404 par que a API externa não conhece
    503 API externa fora do ar e sem cotação recente em cache

    Decisões

    Decisão Motivo
    FastAPI + httpx assíncrono Enquanto espera a API externa, o processo atende outras requisições (o serviço é quase só I/O).
    AwesomeAPI (economia.awesomeapi.com.br) Gratuita, sem cadastro, cobre BRL. ask → sell e bid → buy (por isso sell ≥ buy). Token opcional em EXCHANGE_API_TOKEN aumenta o limite.
    Cache da cotação por 30 s É o bottleneck deste serviço: ver Cache da cotação.
    Mesma moeda (BRL/BRL) responde 1.0 sem chamar a API Evita uma chamada externa inútil (a API devolveria 404).
    401 sem id-account O serviço só deve ser alcançado pelo gateway; sem o header, a requisição veio de outro lugar.
    1 processo uvicorn por container As métricas do prometheus_client ficam na memória do processo; com vários workers cada scrape veria um diferente. Escala com réplicas (EXCHANGE_REPLICAS / replicas no k8s).
    Porta 8080 e nome exchange O gateway encaminha para http://exchange:8080 no compose e no k8s.
    /metrics fora de /exchange/** O gateway só encaminha /exchange/**, então as métricas ficam só na rede interna (o Prometheus raspa direto).
    Imagem python:3.12-slim, usuário 1001, FS somente leitura no k8s Menos pacotes para o Trivy e mesmo padrão de segurança dos outros serviços.

    Configuração

    Variável Padrão
    EXCHANGE_API_URL https://economia.awesomeapi.com.br/json/last API externa
    EXCHANGE_API_TOKEN — token da AwesomeAPI (opcional)
    CACHE_TTL 30 segundos que uma cotação vale (0 desliga o cache)
    CACHE_STALE_TTL 600 quanto tempo uma cotação velha ainda serve se a API cair
    UPSTREAM_TIMEOUT 3 timeout da chamada externa, em segundos

    No compose, EXCHANGE_CACHE_TTL e EXCHANGE_REPLICAS (no .env) viram CACHE_TTL e o número de réplicas.

    """Exchange: cotação entre moedas para usuários autenticados.

Contrato (docs/arquitetura.md do platform):

    GET /exchange/{from}/{to}     header id-account (injetado pelo gateway)
    -> { "sell": float, "buy": float, "date": "YYYY-MM-DD HH:MM:SS", "id-account": "..." }

A cotação vem de uma API de terceiros (AwesomeAPI). Bottleneck tratado aqui:
cada chamada externa custa ~100-500 ms e a API tem limite de requisições, então
guardamos a cotação em memória por CACHE_TTL segundos (ver cache.py).
"""

import os
import re
import time
from contextlib import asynccontextmanager

import httpx
from fastapi import FastAPI, Header, HTTPException, Request, Response
from prometheus_client import CONTENT_TYPE_LATEST, Histogram, generate_latest
from starlette.routing import Match

from .cache import QuoteCache
from .provider import AwesomeApiProvider, PairNotFound, UpstreamError

CURRENCY = re.compile(r"^[A-Za-z]{3}$")

HTTP_SECONDS = Histogram(
    "exchange_http_server_requests_seconds",
    "Tempo de resposta das rotas do exchange",
    ["method", "route", "status"],
    buckets=(0.005, 0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1, 2.5, 5),
)


def create_app(transport: httpx.AsyncBaseTransport | None = None) -> FastAPI:
    """Fábrica do app. Os testes passam um transport falso no lugar da API externa."""

    @asynccontextmanager
    async def lifespan(app: FastAPI):
        timeout = float(os.getenv("UPSTREAM_TIMEOUT", "3"))
        async with httpx.AsyncClient(timeout=timeout, transport=transport) as client:
            provider = AwesomeApiProvider(
                client,
                base_url=os.getenv("EXCHANGE_API_URL", "https://economia.awesomeapi.com.br/json/last"),
                token=os.getenv("EXCHANGE_API_TOKEN") or None,
            )
            app.state.cache = QuoteCache(
                provider.fetch,
                ttl=float(os.getenv("CACHE_TTL", "30")),
                stale_ttl=float(os.getenv("CACHE_STALE_TTL", "600")),
            )
            yield

    app = FastAPI(title="exchange", lifespan=lifespan, docs_url="/exchange/docs",
                  openapi_url="/exchange/openapi.json", redoc_url=None)

    @app.middleware("http")
    async def metrics_middleware(request: Request, call_next):
        start = time.perf_counter()
        status = 500
        try:
            response = await call_next(request)
            status = response.status_code
            return response
        finally:
            # usa o template da rota ("/exchange/{from_}/{to}") e não a URL real,
            # para não criar uma série no Prometheus por par de moedas
            path = next((r.path for r in app.routes if r.matches(request.scope)[0] == Match.FULL), "desconhecida")
            if path != "/metrics":
                HTTP_SECONDS.labels(request.method, path, str(status)).observe(time.perf_counter() - start)

    @app.get("/exchange/health-check")
    @app.get("/health")
    async def health():
        return {"status": "UP"}

    @app.get("/metrics", include_in_schema=False)
    async def metrics():
        # só na rede interna: o gateway só encaminha /exchange/** e o lb não expõe o exchange
        return Response(generate_latest(), media_type=CONTENT_TYPE_LATEST)

    @app.get("/exchange/{from_}/{to}")
    async def exchange(
        from_: str,
        to: str,
        request: Request,
        id_account: str | None = Header(default=None, alias="id-account"),
    ):
        # o gateway sempre injeta o id-account depois de validar o JWT; sem ele a
        # requisição não passou pelo gateway
        if not id_account:
            raise HTTPException(status_code=401, detail="header id-account ausente")
        if not CURRENCY.match(from_) or not CURRENCY.match(to):
            raise HTTPException(status_code=400, detail="moeda deve ter 3 letras (ISO 4217), ex.: USD")

        src, dst = from_.upper(), to.upper()
        if src == dst:
            return {"sell": 1.0, "buy": 1.0, "date": time.strftime("%Y-%m-%d %H:%M:%S"), "id-account": id_account}

        try:
            quote = await request.app.state.cache.get(src, dst)
        except PairNotFound:
            raise HTTPException(status_code=404, detail=f"par {src}-{dst} não suportado")
        except UpstreamError:
            raise HTTPException(status_code=503, detail="API de câmbio indisponível, tente de novo")

        return {"sell": quote.sell, "buy": quote.buy, "date": quote.date, "id-account": id_account}

    return app


app = create_app()

    """Cliente da API de câmbio de terceiros (AwesomeAPI, gratuita e sem cadastro).

    GET https://economia.awesomeapi.com.br/json/last/USD-BRL
    -> {"USDBRL": {"bid": "5.39", "ask": "5.40", "create_date": "2026-11-05 10:00:00", ...}}

"bid" é o preço pelo qual o mercado compra a moeda (buy) e "ask" o preço pelo
qual vende (sell); por isso sell >= buy.
"""

import time
from dataclasses import dataclass

import httpx
from prometheus_client import Histogram

UPSTREAM_SECONDS = Histogram(
    "exchange_upstream_request_seconds",
    "Tempo das chamadas à API de câmbio externa",
    ["outcome"],
    buckets=(0.05, 0.1, 0.25, 0.5, 1, 2, 3, 5),
)


@dataclass(frozen=True)
class Quote:
    sell: float
    buy: float
    date: str


class PairNotFound(Exception):
    """A API externa não conhece o par de moedas."""


class UpstreamError(Exception):
    """A API externa falhou (timeout, 5xx, limite de requisições, resposta inválida)."""


class AwesomeApiProvider:
    def __init__(self, client: httpx.AsyncClient, base_url: str, token: str | None = None):
        self._client = client
        self._base_url = base_url.rstrip("/")
        self._token = token

    async def fetch(self, src: str, dst: str) -> Quote:
        params = {"token": self._token} if self._token else None
        start = time.perf_counter()
        outcome = "error"
        try:
            try:
                resp = await self._client.get(f"{self._base_url}/{src}-{dst}", params=params)
            except httpx.HTTPError as e:
                raise UpstreamError(str(e)) from e

            if resp.status_code == 404:
                outcome = "not_found"
                raise PairNotFound(f"{src}-{dst}")
            if resp.status_code != 200:
                raise UpstreamError(f"status {resp.status_code}")

            try:
                data = resp.json()[f"{src}{dst}"]
                quote = Quote(sell=float(data["ask"]), buy=float(data["bid"]), date=data["create_date"])
            except (ValueError, KeyError, TypeError) as e:
                raise UpstreamError(f"resposta inesperada: {e}") from e

            outcome = "ok"
            return quote
        finally:
            UPSTREAM_SECONDS.labels(outcome).observe(time.perf_counter() - start)

    """Bottleneck: cache da cotação.

Sem cache, cada GET /exchange/USD/BRL vira uma chamada HTTP para a API externa:
latência de rede de terceiros no caminho de toda requisição e risco de bater no
limite de requisições da API (que derruba o serviço para todo mundo).

Decisões:
  - cache em memória por par, TTL curto (CACHE_TTL, padrão 30 s): cotação de
    30 s atrás é aceitável para uma loja, e a cardinalidade é minúscula
    (poucos pares de moedas), então não precisa de Redis;
  - um lock por par: com 200 usuários pedindo USD-BRL no mesmo instante em que
    o cache expira, só UMA chamada vai para a API externa (evita "cache stampede");
  - se a API externa falhar, devolve a última cotação conhecida por até
    CACHE_STALE_TTL (padrão 10 min) em vez de 503 ("stale-if-error").
"""

import asyncio
import time
from typing import Awaitable, Callable

from prometheus_client import Counter

from .provider import PairNotFound, Quote, UpstreamError

CACHE_RESULTS = Counter(
    "exchange_quote_cache",
    "Resultado da consulta ao cache de cotações",
    ["result"],  # hit | miss | stale | error
)

Fetcher = Callable[[str, str], Awaitable[Quote]]


class QuoteCache:
    def __init__(self, fetch: Fetcher, ttl: float, stale_ttl: float, clock: Callable[[], float] = time.monotonic):
        self._fetch = fetch
        self._ttl = ttl
        self._stale_ttl = stale_ttl
        self._clock = clock
        self._entries: dict[tuple[str, str], tuple[Quote, float]] = {}
        self._locks: dict[tuple[str, str], asyncio.Lock] = {}

    def _fresh(self, key: tuple[str, str]) -> Quote | None:
        entry = self._entries.get(key)
        if entry and self._clock() - entry[1] < self._ttl:
            return entry[0]
        return None

    async def get(self, src: str, dst: str) -> Quote:
        key = (src, dst)
        if self._ttl > 0 and (quote := self._fresh(key)):
            CACHE_RESULTS.labels("hit").inc()
            return quote

        lock = self._locks.setdefault(key, asyncio.Lock())
        async with lock:
            # outra requisição pode ter atualizado o cache enquanto esperávamos o lock
            if self._ttl > 0 and (quote := self._fresh(key)):
                CACHE_RESULTS.labels("hit").inc()
                return quote

            try:
                quote = await self._fetch(src, dst)
            except PairNotFound:
                CACHE_RESULTS.labels("miss").inc()
                raise
            except UpstreamError:
                entry = self._entries.get(key)
                if entry and self._clock() - entry[1] < self._stale_ttl:
                    CACHE_RESULTS.labels("stale").inc()
                    return entry[0]
                CACHE_RESULTS.labels("error").inc()
                raise

            CACHE_RESULTS.labels("miss").inc()
            self._entries[key] = (quote, self._clock())
            return quote

    Testes

    pytest com a API externa simulada (httpx.MockTransport), rodando no pipeline de CI (CI/CD): contrato da resposta, sell ≥ buy, 400/401/404/503, 429 da API externa virando 503, mesma moeda sem chamada externa, 50 requisições → 1 chamada externa, e o cache (TTL, stale-if-error, 100 requisições simultâneas → 1 chamada). O smoke test confere a rota de ponta a ponta pelo gateway, inclusive que o id-account que chega é o do usuário logado.

    Verificado em 05/11/2026: 21 testes passando; serviço rodando contra a AwesomeAPI real (200 com sell ≥ buy para USD/BRL e EUR/BRL, 400, 401 e 404 corretos); smoke test completo na plataforma local (GET /exchange/USD/BRL → 200 com o id-account do usuário). Desempenho no teste de carga e em Cache da cotação.
